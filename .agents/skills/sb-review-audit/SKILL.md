# SCU 스토리보드(SB) 품질 자동 검수 스킬

서울사이버대학교(SCU)의 콘텐츠 설계 및 품질검수 지침과 표준 SB 양식을 준수하여 원고와 SB를 자동 검수하는 워크플로우입니다.

---

## 1. 사전 준비 및 입력 파일 확인

1. `input/` 폴더에서 검수 대상 **원고 파일**(`*.hwp`, `*.hwpx`, `*.docx`, `*.pdf`, `*.pptx`)과 **SB 파일**(`*.pptx`)을 탐색합니다.
2. 사용자가 특정 파일명을 지정한 경우 해당 파일을 사용합니다.

---

## 2. 2-Track 하이브리드 검수 절차

### Track 1: 파이썬 정량 서식 검사
다음 명령어를 실행하여 슬라이드 물리 규격, 폰트 크기/볼드, 화면 이탈, 저작권 출처 누락을 1차 검출합니다:

```bash
python SB-Design/run_sb_audit.py -m "input/<원고파일명>" -s "input/<SB파일명>"
```

- **슬라이드 규격**: 가로 33.867cm × 세로 19.05cm (16:9 와이드)
- **본문 최소 폰트**: 20pt 이상, Bold 적용 여부
- **저작권/출처 점검**: 본문에 이미지가 있는데 슬라이드 노트(Notes)에 `#출처` 또는 게티이미지 번호가 누락된 경우 검출

### Track 2: 정성 내용 및 교수설계 검수 (에이전트)
생성된 `SB-Design/audit_payload.json`과 `SB-Design/criteria/prompt_templates.md`를 바탕으로 다음 4대 항목을 정밀 대조합니다:

1. **내용 누락 및 불일치**: 원고의 핵심 개념/이론 누락, 과도한 요약으로 인한 맥락 왜곡
   - **본문 `#1`, `# 1` 표기**: 슬라이드 노트 출처와 매핑된 정상 인용 앵커이므로 설명 누락 오류로 오탐하지 않음
2. **정보과밀 & 가독성**: 슬라이드당 과도한 줄글 나열 시 2장 분할 또는 탭 전환 제안
3. **교수설계 논리**:
   - 학습목표 행동 진술 적절성 (목표 분류 표는 '기억/이해/적용/분석/창안' 중 유사하면 정상 인정)
   - **작업자 확인요청 말풍선(`To.교수님` 등) 및 내용 검수**: 말풍선 도형 자체는 오류가 아니며, 파워포인트 네이티브 메모(Comment)에는 **"확인요청 사항 있음"**으로 반드시 추가 기록함. **단, 말풍선 안의 사유나 주장과 무관하게 슬라이드 본문/표의 내용이 원고와 불일치·누락·왜곡된 경우 반드시 내용 검수에서 정식 오류로 지적해야 함**
   - **학습정리 판정 기준**: 원고에 이미 학습정리 내용이 있고 이를 반영한 경우 정상 판정(오류 아님). 원고 자체에 내용이 아예 없거나 공란인 경우에만 결함으로 지적하며 본문 핵심 내용을 요약한 **"AI 추천 완성 문안"**을 직접 작성하여 제공
4. **저작권 및 출처 점검**:
   - 통상 아이콘/픽토그램 등 작은 장식용 이미지는 출처 표시 없어도 무방함
5. **시각화/도해화 제안**: 단순 텍스트 나열 슬라이드를 프로세스형(`A→B`), 대비형(`A↔B`), 카드형으로 도해화 제안
6. **'화면설명' 영역 검수 완전 제외 (필수)**: 슬라이드 우측 '화면설명' 영역은 작업자의 연출/설명 지시 공간이므로, 해당 영역의 텍스트, 서식, 플레이스홀더 등은 모두 검수 대상에서 완전히 제외함(오류 지적 금지)

---

## 3. 결과 보고서 작성 및 출력 규칙 (★ 1쌍 산출물 디폴트)

검수 완료 시 최종 산출물은 **동일한 파일명(타임스탬프 포함)의 1쌍(Pair)**으로 반드시 함께 생성하여 제공합니다:
1. **마크다운 검수 보고서**: `output/SB_검수결과_<SB파일명>_YYMMDD_HHMM.md`
2. **검수 메모 반영 파워포인트**: `output/SB_검수결과_<SB파일명>_YYMMDD_HHMM.pptx` (`SB-Design/scripts/add_comments_to_pptx.py` 실행)

### 작성 및 구성 규칙:
1. **저작권, 출처 미기재**: 표에 개별 행으로 나열하지 않고, 상단 강조 블록에 `> **저작권, 출처 미기재** : P. 06, P. 11... (총 N개 슬라이드)` 형태로 한 번에 슬라이드 번호만 쭈욱 나열합니다.
2. **세부 검수 결과 표**: `슬라이드 번호 | 구분 | 지적사항 (문제점) | 수정요청 (구체적 개선안)` 포맷으로 핵심 지적사항만 집중 표시합니다.
3. **PPTX 메모(Comment) 자동 삽입**: 지적사항이 있는 슬라이드에만 파워포인트 네이티브 메모를 생성하며, P. 69 등 추천 문안이 있는 경우 완성 문안 전체를 메모 본문에 포함합니다.
