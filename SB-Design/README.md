# 📘 SCU SB-Design 스토리보드 자동 검수 시스템

서울사이버대학교(SCU)의 **콘텐츠 설계 및 품질검수 지침**과 **표준 SB 양식**을 준수하여, 원고(HWP, HWPX, DOCX, PDF, PPTX)와 스토리보드 초안(PPTX)을 자동 분석하고 검수 보고서를 발행하는 패키지입니다.

이 폴더(`SB-Design/`)는 완전히 독립적인 모듈로 구성되어 있어, 다른 프로젝트나 작업자에게 이 폴더만 복사·공유해도 즉시 재사용할 수 있습니다.

---

## 📂 폴더 구조

```text
SB-Design/
├── criteria/                           # 검수 기준 정의 문서
│   ├── scu_guidelines.md               # SCU 품질검수 지침서 원문 및 기준 규격
│   └── prompt_templates.md             # LLM 에이전트용 정성 검수 프롬프트
├── contents/                           # ★ 과목(콘텐츠)별 고유 특화 기준 폴더
│   ├── 글로벌AI커머스.md               # 해당 과목 전용 검수 규칙 (학습목표, 예블릿, 콜론 등)
│   └── _template.md                    # 신규 과목 추가용 표준 템플릿
├── scripts/                            # 핵심 파이썬 스크립트 모듈
│   ├── doc_parser.py                   # 원고 통합 파서 (HWP, HWPX, DOCX, PDF, PPTX)
│   ├── sb_parser.py                    # SCU 표준 SB 정밀 파서 (역할 분류, 메타데이터, 슬라이드 노트)
│   ├── pptx_layout_checker.py          # Track 1 레이아웃/디자인/서식 정량 검사기
│   └── report_generator.py             # 결과 병합 및 마크다운 리포트 생성기
├── run_sb_audit.py                     # 원클릭 실행 진입점 (CLI 및 AI 에이전트용)
└── README.md                           # 본 사용자 안내서
```

## ⚙️ 사전 환경 설정 (필요 패키지)

파이썬 3.8 이상 환경에서 아래 명령어로 필요한 패키지를 설치합니다:

```bash
pip install python-pptx python-docx olefile pdfplumber
```
* **HWP/HWPX 처리**: 한컴오피스 프로그램 설치 여부와 무관하게 `olefile` 및 파이썬 내장 라이브러리로 100% 동작합니다.

## 🚀 사용 방법

### 1. 자동 탐색 모드 (가장 간편한 방법)
`input/` 폴더에 **원고 파일**과 **SB 파일**을 넣어두고 아래 명령어를 실행하면 자동으로 파일을 감지하여 검수합니다:

```bash
python SB-Design/run_sb_audit.py
```

### 2. 파일 명시 지정 모드
원하는 파일 경로를 직접 지정하여 실행할 수도 있습니다:

```bash
python SB-Design/run_sb_audit.py -m "input/원고.hwp" -s "input/SB_01_v1.pptx"
```

### 3. AI 에이전트 대화 모드
채팅창에서 **"SB검수해줘"**라고 요청하면, AI 에이전트가 `run_sb_audit.py`를 실행하여 Track 1 정량 검사를 수행하고, 추출된 텍스트 데이터를 바탕으로 Track 2 정성 검수(내용 누락, 정보과밀, 교수설계 논리, 도해화 제안)를 수행하여 종합 리포트를 발행합니다.

## 📚 과목(콘텐츠)별 고유 특화 기준 관리 (`contents/`)

약 15~20개 이상의 과목을 운영할 때, 각 과목마다 교수자 요구사항이나 독특하게 반영해야 하는 전용 규칙이 다릅니다.
`SB-Design/contents/` 폴더에 **`<과목명>.md`** 파일을 넣어두면, 시스템이 파일명을 분석하여 **해당 과목의 특화 기준을 자동으로 감지하고 검수에 반영**합니다.

1. **신규 과목 추가 방법**:
   - `SB-Design/contents/_template.md`를 복사하여 `SB-Design/contents/<과목명>.md` 파일 생성
   - 해당 과목에서만 지켜야 하는 고유 규칙(학습목표 서술 방식, 콜론 띄어쓰기, 예블릿, 템플릿 높이, 고유 서브타이틀 등) 기재
2. **자동 매칭 동작**:
   - 검수 실행 시 원고나 SB 파일명에 과목명이 포함되어 있으면 자동으로 로드되어 검수 보고서 상단에 `[적용 과목 특화 기준: contents/<과목명>.md]`로 표시되며 검수에 반영됩니다.
   - 예: `contents/글로벌AI커머스.md` (글로벌AI커머스 1~15주차 전체에 전용 합의 규칙 자동 적용)
3. **★ 기준 보완 요청 시 필수 확인 질문 원칙**:
   - 사용자가 검수 기준 수정을 요청할 때, AI는 반드시 **"① 모든 과목에 공통 적용할 전사 기준인가요?"** vs **"② 현재 과목({과목명})에만 적용할 고유 특화 기준인가요?"**를 먼저 확인 질문한 후, 사용자의 선택에 따라 `criteria/scu_guidelines.md`(전체 공통) 또는 `contents/<과목명>.md`(과목 전용)에 분리 반영합니다.

## 🔍 2-Track 검수 세부 기준

| 구분 | 검수 트랙 | 주요 검사 항목 | 검사 주체 |
|---|---|---|---|
| **Track 1** | **정량 룰 검사** | • 슬라이드 규격 (33.867 × 19.05cm, 16:9)<br>• 본문 폰트 최소 기준 (20pt 이상, Bold 적용 여부)<br>• 슬라이드 화면 경계 이탈(오버플로우) 검사<br>• 슬라이드 노트(Notes) 내 이미지 저작권/#출처 누락 검사<br>• 개조식 종결어미 마침표 및 괄호 마침표 오표기 검사 | 파이썬 스크립트 (`pptx_layout_checker.py`) |
| **Track 2** | **정성 AI 검수** | • 원고 vs SB 내용 누락 및 왜곡 대조<br>• 정보과밀 슬라이드 감지 및 슬라이드 2장 분할/탭 제안<br>• 교수설계 논리 (학습목표 행동 진술, 퀴즈 피드백)<br>• 줄글 나열 슬라이드에 대한 프로세스/대비형 도해화 제안 | LLM 에이전트 (`criteria/prompt_templates.md`) |

## 📊 결과물 산출 (`output/`)

검수가 완료되면 `output/` 폴더에 다음과 같은 마크다운 보고서가 생성됩니다:
- **파일명**: `output/SB_검수결과_<SB파일명>_YYMMDD_HHMM.md`
- **포맷**:
  ```markdown
  | 슬라이드 번호 | 구분 | 지적사항 (무슨 문제인가요?) | 수정요청 (이렇게 바로 고쳐주세요!) |
  | :---: | :---: | :--- | :--- |
  | **P. 06** | 학습목표 | 첫 번째 목표에 '이해할 수 있다'가 쓰여 있어 모호함 | '~이해할 수 있다'를 '~설명할 수 있다'로 바꿔주세요. |
  | **P. 12** | 화면구성 | 긴 텍스트 한 줄만 덜렁 들어가 있어 가독성 저하 | 아래에 박스 2개를 나란히 넣고 [판매장소 선택 X] vs [판매전략 선택 O] 로 대비되게 만들어주세요. |
  ```

## 💡 검수 피드백 작성 원칙: "누구나 바로 알아듣는 쉬운 실무 지침"

본 시스템을 재사용하는 모든 작업자와 AI는 지적사항 및 수정요청을 작성할 때 **추상적인 학술 용어(행동목표 모호, 도해화 필요, 대등 구조 등)를 절대 쓰지 않습니다.**
현업 제작자가 보고서를 보자마자 PPT에서 바로 손을 움직일 수 있도록 **초등학생도 이해하는 구체적인 행동 지시어**로 작성합니다.

- ⭕ **학습목표**: "'~을 이해할 수 있다' 대신 **'~을 설명할 수 있다'**로 바꿔주세요."
- ⭕ **도해화**: "텍스트 한 줄만 두지 마시고, 아래에 박스 2개를 나란히 넣어 **[왼쪽: 판매장소 선택 X] / [오른쪽: 판매전략 선택 O]**로 넣어주세요."
- ⭕ **서브타이틀**: "상단 서브타이틀 박스에 **'Amazon 판매자가 생각할 중요한 질문'**이라고 딱 적어주세요."
- ⭕ **레이아웃**: "오른쪽 박스가 화면 밖으로 삐져나갔으니, 가로 너비를 줄여서 **화면 안쪽으로 쏙 넣어주세요.**"
