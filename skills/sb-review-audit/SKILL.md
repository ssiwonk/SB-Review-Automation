# SCU 스토리보드(SB) 품질 자동 검수 스킬

서울사이버대학교(SCU)의 콘텐츠 설계 및 품질검수 지침과 표준 SB 양식을 준수하여 원고와 SB를 자동 검수하는 워크플로우입니다.

---

## 1. 사전 준비 및 입력 파일 확인

1. `input/` 폴더에서 검수 대상 **원고 파일**(`*.hwp`, `*.hwpx`, `*.docx`, `*.pdf`, `*.pptx`)과 **SB 파일**(`*.pptx`)을 탐색합니다.
2. 사용자가 특정 파일명을 지정한 경우 해당 파일을 사용합니다.

---

## 2. 2-Track 하이브리드 검수 절차

### Track 1: 파이썬 정량 서식 검사
다음 명령어를 실행하여 슬라이드 물리 규격, 폰트 크기/볼드, 화면 이탈, 저작권 출처 누락을 1차 검출합니다:

```bash
python SB-Design/run_sb_audit.py -m "input/<원고파일명>" -s "input/<SB파일명>"
```

- **슬라이드 규격**: 가로 33.867cm × 세로 19.05cm (16:9 와이드)
- **본문 최소 폰트**: 20pt 이상, Bold 적용 여부
- **저작권/출처 점검**: 본문에 이미지가 있는데 슬라이드 노트(Notes)에 `#출처` 또는 게티이미지 번호가 누락된 경우 검출

### Track 2: 정성 내용 및 교수설계 검수 (에이전트)
생성된 `SB-Design/audit_payload.json`과 `SB-Design/criteria/prompt_templates.md`를 바탕으로 다음 4대 항목을 정밀 대조합니다:

1. **내용 누락 및 불일치**: 원고의 핵심 개념/이론 누락, 과도한 요약으로 인한 맥락 왜곡
2. **정보과밀 & 가독성**: 슬라이드당 과도한 줄글 나열 시 2장 분할 또는 탭 전환 제안
3. **교수설계 논리**:
   - 학습목표 행동 진술 적절성
   - **학습정리 누락 시**: 단순 지적에 그치지 않고 본문 핵심 내용을 요약한 **"AI 추천 완성 문안"**을 직접 작성하여 제공
4. **시각화/도해화 제안**: 단순 텍스트 나열 슬라이드를 프로세스형(`A→B`), 대비형(`A↔B`), 카드형으로 도해화 제안

---

## 3. 결과 보고서 작성 및 출력 규칙

최종 결과물은 `output/SB_검수결과_<SB파일명>_YYMMDD_HHMM.md`에 저장하며, 다음 4대 표준 항목 체계로 작성합니다:

1. **1. 총평**:
   - **지적사항 갯수 합계 표**: 내용 검수 결과(N건), 레이아웃 검수 결과(N건), 저작권 및 출처 점검 결과(N건), 총합(N건) 표 제공
   - **종합 의견**: 전반적인 설계 상태 및 주요 조치 권고사항 요약
2. **2. 내용 검수 결과**:
   - 원고 대조 내용 누락·왜곡, 교수설계 논리(학습목표, 퀴즈 피드백), 정보과밀 분할 제안 등
   - 표 포맷: `슬라이드 번호 | 구분 | 지적사항 (문제점) | 수정요청 (구체적 개선안)`
   - 학습정리 누락/빈약 시: "AI 추천 완성 문안"을 직접 서술하여 제공
3. **3. 레이아웃 검수 결과**:
   - 슬라이드 물리 규격, 본문 폰트(20pt Bold), 화면 이탈(오버플로우), 도해화(시각화) 제안 등
   - 표 포맷: `슬라이드 번호 | 구분 | 지적사항 (문제점) | 수정요청 (구체적 개선안)`
4. **4. 저작권 및 출처 점검 결과**:
   - 슬라이드 노트 출처(`#1`, `#출처/N`, 유료 이미지 번호) 미기재 슬라이드 번호 나열:  
     `> **저작권, 출처 미기재** : P. 06, P. 11... (총 N개 슬라이드)`
   - 미기재 이미지에 대한 촬영 전 라이선스/출처 보완 가이드 안내

---

## 4. 임시 파일 자동 정리 및 최종 산출물 단일화 (필수)

1건의 검수 보고가 완료되면 다음 클린업 절차를 즉시 수행합니다:
1. **임시 파일 삭제**: 검수 파이프라인 중간에 생성된 `SB-Design/audit_payload.json` 및 임시 스크립트/데이터 파일 즉시 삭제
2. **이전 중복 초안 정리**: 동일한 SB 파일에 대해 중간에 생성된 미완성/중복 초안 보고서가 output에 있을 경우, 최신 최종 보고서 1개만 남기고 이전 임시 파일 삭제
3. **최종 결과**: 검수 대상 1건당 단 1개의 완성된 마크다운 보고서(`output/SB_검수결과_<SB파일명>_YYMMDD_HHMM.md`)만 보존
